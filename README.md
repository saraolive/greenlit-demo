# demo-shop

demo-shop is an intentionally imperfect storefront used to exercise the [Greenlit](https://greenlit.sh) PR gate. [PR #1](https://github.com/saraolive/greenlit-demo/pull/1) shows Greenlit blocking an AI-generated payments change with security issues; [PR #2](https://github.com/saraolive/greenlit-demo/pull/2) shows a clean change passing.
